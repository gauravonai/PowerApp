# v2.0.6: what was broken, what changed, how to import

## Your report and the cause

| You saw | Cause | Fix in v2.0.6 |
|---|---|---|
| BOM Compare / Check Stock / BOM check show nothing | 1) The debug app *EDS Lab Material Portal_1* has Copilot edits (simplified `nfStock`, test `colBom`, galleries pointed at test data). 2) Tables connected twice (`tblParts_1`…). 3) Power Fx 1.0 off in v2.0.2. | Import v2.0.6 into a **new** app (steps below). | A new request did not appear under My Requests | Requests raised without a login were saved with an empty requester; the identity also changed when a person's Email was filled in | Every screen sends you to Login if nobody is logged in. Requests are keyed on the **username**, and My Requests also matches the email, so old and new rows both show. The save re-reads the tables first and confirms the request really landed before going to My Requests. |

## Other fixes found by checking every button
- **Shortfall request**: the original line now keeps what was really reserved/released; the shortfall moves to the new SHT request (no double counting).
- **Ongoing Purchase → Add**: one purchase row per part **and request** (no more "REQ-1, REQ-2" in one cell).
- **Cost Sheet paste**: Part, Qty, Cost / Unit with or without Sr and description; a qty-only line takes the cost from the parts list; tells you how many lines loaded.
- **Invoice**: a new invoice cannot reuse an existing number; re-saving an opened invoice keeps its material cost; picking a request (or *Create invoice* on a request) loads its lines.
- **Brand New Purchase Part**: Edit changes the row in place (nothing lost if you change your mind); *Your New Part Requests* also lists what you just submitted even if you typed another requester name; numbering re-reads the sheet first; a failed save keeps your list.
- **Team Access**: Lab Lead only (menu, page and buttons). Role is typed text, so `Engineer, Manager` stays two roles.
- Login: eye icon to show / hide the password.
- Dashboard / lists: My Requests count ignores closed requests, PR bars ignore rejected PRs, High Demand opens on *Last 12 Months*.
- System Check: 18 rows (all 12 tables + BOM reader test).
- Background: new backlit backhoe-loader scene, machine on the right so the login card never hides it.

## Import (do exactly this once)
1. Power Apps → **Apps** → delete (or rename) *EDS Lab Material Portal_1* (the one Copilot edited). Don't reuse it.
2. **Import canvas app** → `EDS-Lab-Portal-v2.0.6.msapp` → it opens as a new app.
3. **Data** → *Add data* → Excel Online (Business) → your workbook → tick all **12** tables once.
   The names must be plain (`tblParts`, not `tblParts_1`). If `_1` appears, remove both copies and add once.
4. **Settings → General → Data row limit = 2000**.
5. Play → **Login** page → **System Check** (top right). All 18 rows must say **OK**. Send a screenshot if one doesn't.
6. Old requests saved with an empty *RaisedByEmail* (raised before login was enforced): type the person's username into that cell in the Requests table once.
